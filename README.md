# СМС тестовое задание

Внесены изменения для упрощения читаемости кода. Тест написан без применения Page Object.
### Что поменялось 
В задании 1:
 - Вводные данные из файла constant перенесены в файл с решением
В задании 2:
 - Запуск браузера и его закрытие перенесены из фикстуры в тело теста
 - Вспомогательные функции из хелперов перенесены в тело теста
 - Локаторы перенесены в тело теста.

### Структура проекта
Общее:
- `.gitignore` - список игнорируемых гитом файлов и папок
- `README.md` - описание проекта
- `requirements.txt` - файл с зависимостями
Первое задание:
- `task_1.py` - код для первого задания, на выходе получаем список путей к папкам с нужными файлами и количество этих файлов в каждой папке
- `task_1_with_separation.py` - первое задание, добавлена функция разбиения на несколько списков
Второе задание:
- `test_sorting_WB.py` - файл с автотестом


### Запуск автотестов

**Установка зависимостей**

> `$ pip install -r requirements.txt`

**Запуск автотеста с выводом печати в консоль**

>  `$ pytest -s`
