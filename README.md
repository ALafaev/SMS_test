# СМС тестовое задание

### Структура проекта
Общее:
- `.gitignore` - список игнорируемых гитом файлов и папок
- `README.md` - описание проекта
- `requirements.txt` - файл с зависимостями
Первое задание:
- `constant.py` - файл содержит исходные данные для выполнения кода
- `task_1.py` - код для первого задания, на выходе получаем список путей к папкам с нужными файлами и количество этих файлов в каждой папке
- `task_1_with_separation.py` - первое задание, добавлена функция разбиения на несколько списков
Второе задание:
- `test_sorting_WB.py` - файл с автотестом
- `conftest.py` - файл с фикстурой на запуск браузера
- `helpers.py` - файл содержит вспомогательную функцию для вывода на печать десяти карточек
- `locators.py` - файл содержит локаторы и методы для генерации динамических локаторов


### Запуск автотестов

**Установка зависимостей**

> `$ pip install -r requirements.txt`

**Запуск автотеста с выводом печати в консоль**

>  `$ pytest -s`
